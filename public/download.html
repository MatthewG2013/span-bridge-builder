SPAN 便携版把前端、后端和启动入口打包在一起。完整版内置 Node.js 运行时， 不需要安装 npm、不需要编译，解压后双击入口即可启动服务器并自动打开浏览器。

推荐 · 含 Node 运行时

完整便携版

适合直接发给朋友或放到 U 盘。解压后双击「START-SPAN.bat」，浏览器会自动打开游戏窗口。

  • Windows 10 / 11 64 位
  • 内置 Node.js，无需任何环境配置
  • 存档保存在文件夹内的 data 目录

注意：浏览器不能直接运行本地 .bat 文件。请先下载并解压压缩包，再从资源管理器双击入口。 Windows 可能会对未签名脚本提示安全警告，可选择「更多信息 → 仍要运行」。
