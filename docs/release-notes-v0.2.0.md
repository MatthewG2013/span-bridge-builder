# SPAN v0.2.0 — 蓝图 2.0

SPAN 造桥模拟器的第一个公开发行版。纯 HTML + TypeScript + Node 服务器存储的网页造桥模拟器：在预算内连接两岸、铺设路面，让卡车安全通过。

## 本次更新

### 视觉

- 黄昏工程蓝图场景重绘：岩层、雾、水面反光、施工塔吊、测量旗、飞鸟。
- 预算环、结构完整度、最大应力、拉压图例与实时测试 HUD。
- 卡车悬挂、车灯、扬尘；断裂碎屑、成功粒子、失败镜头震动。
- 重新设计材料卡、排行榜、弹窗、字体、间距与三档响应式布局。

### 物理

- 直接节点引用与 `Math.sqrt` 热路径优化。
- 自适应约束迭代（4–10 次）。
- 路面拓扑缓存：仅在断梁时重新寻路。
- 拉/压分离损伤：木材抗压弱、钢材抗拉强。
- 卡车前后轴载荷随桥面坡度变化。
- 天空、远山、岩体离屏缓存。

### 分发

- 新增 **Windows 完整便携版**：内置 Node.js 运行时，解压后双击 `START-SPAN.bat` 即可启动并自动打开浏览器。
- 新增 **精简版**：需要系统 Node.js 22.5+。
- 新增在线下载页与本地 JSON 存档、排行榜。

## 下载

- `SPAN-0.2.0-portable-win64.zip` — 完整便携版（内置 Node.js，约 32.7 MB）
- `SPAN-0.2.0-lite-win64.zip` — 精简版（需要 Node.js 22.5+，约 60 KB）
- `SHA256SUMS.txt` — 压缩包校验值

## 使用

1. 下载并解压压缩包。
2. 进入解压后的文件夹。
3. 双击 `START-SPAN.bat`。
4. 浏览器自动打开 <http://127.0.0.1:4173>。
5. 关闭启动窗口或按 `Ctrl+C` 停止服务器。

存档位于程序目录下的 `data/db.json`；升级时保留 `data` 文件夹即可。

## 开发

```bash
npm install
npm run build
npm test
npm run launch
```

打包便携版：

```bash
npm run package
```

## 已知边界

- 当前仅提供 Windows 便携包；源码可在其他平台通过 Node.js 运行。
- 排行榜成绩由客户端提交，服务端进行范围、预算与字段校验，尚未加入回放防作弊。
- 暂无账号密码体系、钢索、关卡编辑器与多人联机。

完整说明见仓库 README 与 `release/使用说明.txt`。
