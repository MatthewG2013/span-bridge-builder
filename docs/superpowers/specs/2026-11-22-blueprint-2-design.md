# SPAN · 蓝图 2.0 UI 与物理升级设计

日期：2026-11-22

## 目标

在保留现有玩法、存档格式和服务器 API 的前提下，把初版提升为更完整、更有质感的作品：视觉上强化黄昏工程蓝图氛围，物理上提高稳定性、受力表现与性能。

## 视觉方向

- 保留深蓝夜幕、暖橙日落、青色蓝图网格，不更换主题。
- 建立更清晰的三级层次：环境（Canvas 场景）→ 战场 HUD（预算、测试、完整度）→ 控制台（材料、存档、排行榜）。
- 标题使用系统窄体字（Bahnschrift / DIN 风格），数值统一等宽字体；正文最小字号提升到 9–11px。
- 预算从普通进度条升级为环形仪表 + 进度条 + 数字，剩余预算低于 15% 时变为警示色。
- 测试 HUD 增加「结构完整度」「最大应力」「通行进度」「剩余时间」，拉/压使用不同颜色。
- Canvas 增加岩层、雾、水面反光、施工标记、锚点铭牌、卡车扬尘、车灯与碰撞碎屑。
- 失败时短暂镜头震动与红色边缘闪烁；成功时金色粒子与结算卡。
- 侧栏材料卡、排行榜、空状态、快捷键提示全部重排，移动端保持可读字号。

## 物理方向

- **自适应约束迭代**：最低 5 次、最高 14 次，误差低于阈值提前结束；稳定状态减少计算。
- **直接节点引用**：梁缓存两端节点与逆质量，消除内层 `Map` 查找。
- **路面拓扑缓存**：测试开始时计算一次路面节点序列，仅在梁断裂时重新寻路，不再每个子步跑 Dijkstra。
- **拉压分离损伤**：木材抗压弱、钢材抗拉强；分别使用 tension / compression 限值，短时过载累积损伤后断裂。
- **更真实的卡车载荷**：前后轴分配，按桥面坡度轻微调整；视觉上增加悬挂起伏与扬尘。
- **离屏缓存**：天空、远山、岩体预渲染到离屏 Canvas；水面、桥梁、粒子逐帧绘制。
- **稳定性保护**：限制单次位置修正、节点速度、NaN 回滚，避免极端结构导致数值爆炸。

## 兼容性

- 关卡几何、预算、材料价格、存档 JSON、HTTP API 保持不变。
- 现有三关的可通关设计必须继续通过。
- 自动化测试保留并补充：拉压断裂、路面拓扑缓存、物理吞吐基准。
- 验收视口：1440×900、1024×768、390×844；无横向溢出、无控制台错误。

## 验收标准

- `npm run build` 与 `npm test` 通过。
- 三关实机可通关，失败/成功流程正常。
- 物理基准（29 根构件、3000 子步）相对初版有明显吞吐提升。
- 新 UI 在桌面、平板、手机均保持可读、可操作。
